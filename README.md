# Daily Routine

แอปเช็กลิสต์และตารางประจำวันสำหรับใช้คนเดียว เปิดบนมือถือได้ ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องสมัครอะไร

## มีอะไรบ้าง

- **วันนี้**: เช็กลิสต์รายวัน (ต่างกันระหว่างวันธรรมดา เสาร์ และอาทิตย์) พร้อมเปอร์เซ็นต์ จำนวนวันติดต่อกัน และช่องบันทึก
- **ตาราง**: ตารางเวลาวันจันทร์-ศุกร์ และเสาร์-อาทิตย์ (ไฮไลต์ช่วงเวลาปัจจุบัน)
- **ฝึก**: โปรแกรมออกกำลังกายที่บ้านและแบบฝึกการสื่อสารรายวัน
- **ไรเดอร์**: เคล็ดลับเรื่องอาหาร น้ำ ความปลอดภัย และการยืดเหยียดระหว่างรอออเดอร์
- **ผลลัพธ์**: กราฟ 7 วันล่าสุด เป้าหมาย 4 สัปดาห์ และปุ่มสำรอง/นำเข้าข้อมูล

ข้อมูลที่ติ๊กไว้เก็บใน `localStorage` ของเบราว์เซอร์ในเครื่องนั้นเท่านั้น

## ใช้งานทันที (ในเครื่อง)

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

## อัปขึ้นเว็บด้วย GitHub Pages (ใช้บนมือถือ)

1. สร้าง repo ใหม่บน GitHub (ตั้งเป็น Private ก็ได้ ถ้าบัญชีรองรับ Pages กับ repo private)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `manifest.json`, `sw.js`, `icon.svg`, `README.md`) ไว้ที่ root ของ repo
3. ไปที่ **Settings → Pages**
4. ที่ Source เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด Save
5. รอ 1-2 นาที จะได้ลิงก์รูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

### ติดตั้งเป็นแอปบนมือถือ

- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "เพิ่มลงในหน้าจอหลัก" / "ติดตั้งแอป"
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → "เพิ่มในหน้าจอโฮม"

เปิดแล้วใช้งานแบบออฟไลน์ได้

## แก้ไขตารางและเช็กลิสต์

เปิด `index.html` แล้วดูส่วน `ข้อมูลโปรแกรม (แก้ไขตรงนี้ได้เลย)` ใน `<script>`:

- `SCHEDULE`: ตารางเวลา
- `WORKOUT`: โปรแกรมออกกำลังกายแต่ละวัน
- `TALK`: แบบฝึกการสื่อสาร
- `GOALS`: เป้าหมาย 4 สัปดาห์
- `checklistFor()`: รายการเช็กลิสต์รายวัน

หลังแก้ไขแล้วอัปขึ้น GitHub ใหม่ ถ้ามือถือยังเห็นของเก่า ให้เปลี่ยนเลขเวอร์ชัน `CACHE` ในไฟล์ `sw.js` (เช่น `daily-routine-v2`)

## สำรองข้อมูล

แท็บ **ผลลัพธ์** มีปุ่ม "สำรองข้อมูล" (ดาวน์โหลดไฟล์ JSON) และ "นำเข้า" ใช้ย้ายข้อมูลข้ามเครื่องหรือกันข้อมูลหายตอนล้างข้อมูลเบราว์เซอร์

## หมายเหตุ

โปรแกรมออกกำลังกายเป็นแนวทางทั่วไป ถ้ามีโรคประจำตัวหรืออาการบาดเจ็บ ควรปรึกษาแพทย์ก่อน และถ้านอนไม่พอจนเพลีย ให้ตัดออกกำลังกายวันเบาก่อน ไม่ตัดการนอน
